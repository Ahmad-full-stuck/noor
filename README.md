# نُور — نظام الحياة الشخصي

تطبيق عربي باتجاه RTL لتنظيم المهام اليومية، القيم والأهداف، المراحل والمشاريع، التدوين، المكتبة، جلسات التركيز، الإحصائيات والأرشيف.

## التشغيل المحلي

يتطلب Node.js 22.5 أو أحدث.

- **Windows:** افتح `start.bat` بنقرتين.
- **macOS / Linux:** شغّل `./start.sh`.
- أو من مجلد المشروع: `node server.js`.

يفتح التطبيق محلياً على `http://127.0.0.1:4173/`. في وضع السيرفر المحلي تحفظ البيانات في قاعدة SQLite داخل مجلد التشغيل، وتُنشأ النسخ الاحتياطية محلياً. لا ترفع ملفات البيانات أو النسخ الاحتياطية إلى مستودع عام.

## وضع المتصفح الثابت

عند فتح `index.html` مباشرة، يستخدم التطبيق تخزين المتصفح `localStorage`. هذه البيانات مرتبطة بالمتصفح والجهاز؛ لا تعتمد عليها بوصفها نسخة احتياطية، ولا تستخدم رابطاً عاماً لتخزين معلومات شخصية.

## حماية البيانات

هذا المستودع عام، ولذلك يحتوي على **كود المصدر فقط**. أُزيلت من أحدث شجرة الملفات قاعدة البيانات والملفات المرفوعة وبيانات التهيئة التي لا ينبغي نشرها. ويُستثنى من ذلك أن Git يحتفظ بالالتزامات السابقة: **الإزالة في الالتزام الحالي لا تمحو النسخ السابقة من سجل المستودع**. لا تعتبر السجل العام مخزناً خاصاً؛ إذا احتوت نسخ سابقة على معلومات خاصة أو بيانات دخول، فدوّر بيانات الدخول المعنية ونظّف سجل Git أو انقل المصدر إلى مستودع نظيف مناسب.

تذكّر أن قفل واجهة JavaScript في النسخة الثابتة ليس بديلاً عن مصادقة خادمية أو تشفير حقيقي. لا تضع أسراراً أو مفاتيح وصول داخل ملفات الواجهة أو المستودع.
